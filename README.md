## 🚀 Installation Locale

Si vous souhaitez explorer le code ou lancer le projet localement :

1.  **Cloner le projet :**
    ```bash
    git clone https://github.com/mehdiabakri/portfolio-mehdi-abakri-developpeur-web.git
    ```
2.  **Installer les dépendances :**
    ```bash
    npm install
    ```
3.  **Lancer le serveur de développement :**
    ```bash
    npm run dev
    ```
